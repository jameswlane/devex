# Backend Development

This page sets up a backend development machine on Debian or Ubuntu with commands that work on the current CLI:

- Git, curl and Docker Engine from the application catalog
- Go and Python through mise
- kubectl and Helm at pinned versions from the built-in `devops` lifecycle template
- PostgreSQL and Redis containers from the built-in `databases` lifecycle template

## Prepare

`devex init` writes the default application catalog. Catalog installs and template plans need it ([#466](https://github.com/jameswlane/devex/issues/466)).

```bash
devex init --profile backend --non-interactive
```

Installs don't download the mise and Docker plugins on their own yet ([#460](https://github.com/jameswlane/devex/issues/460)), so install them first:

```bash
devex plugin install package-manager-mise
devex plugin install package-manager-docker
```

## The built-in backend template

DevEx ships a `backend` template with Git, Docker, kubectl, Helm, PostgreSQL, Redis and RabbitMQ. You can inspect and plan it, but a real install doesn't finish yet: its kubectl and Helm steps fail, and it plans a `mongodb` package that Debian and Ubuntu don't ship ([#463](https://github.com/jameswlane/devex/issues/463)).

```bash
devex template info backend
devex template plan backend --action install --non-interactive
devex install --template backend --non-interactive --dry-run
```

## Install the tools

```bash
# Git, curl and Docker Engine
devex install git curl Docker --non-interactive

# mise, then the newest Go and Python
devex plugin run package-manager-mise ensure-installed
devex install Go Python --non-interactive

# kubectl and Helm, pinned through mise
devex install --template devops --answer tools=kubectl,helm --non-interactive
```

mise adds its activation line to `~/.bashrc`. Open a new terminal to get `go`, `python`, `kubectl` and `helm` on your PATH, or run them through `~/.local/bin/mise exec --`.

For C compilers and `make`, run `sudo apt-get install build-essential`. The catalog's `"Build Essential"` app checks for `make` and `gcc` before it installs them, so it fails on a fresh machine ([#471](https://github.com/jameswlane/devex/issues/471)).

To pin language versions instead of taking the newest, run `devex plugin run package-manager-mise install go@1.25 python@3.13`. The [DevOps example](/docs/examples/devops) covers the other `devops` inputs, including kind, Terraform, OpenTofu and the AWS CLI.

## Local databases

The `databases` template runs PostgreSQL 16 and Redis 7 in Docker containers. They're published on 127.0.0.1 only, and data is kept in named volumes.

```bash
devex install --template databases \
  --answer databases=postgres,redis \
  --answer mysql_password=unused \
  --non-interactive
```

<Callout type="info">
The template asks for `mysql_password` even when you don't select MySQL ([#465](https://github.com/jameswlane/devex/issues/465)). Any value works. Select `mysql` to run MySQL 8 too; the value is then its root password.
</Callout>

Install Docker from the catalog, as in the previous section, before you run this template. The template's own Docker step fails on a fresh machine ([#470](https://github.com/jameswlane/devex/issues/470)).

Installing Docker adds you to the `docker` group, but your current session doesn't pick up the new group. Log out and back in (or run `newgrp docker`) before you install the database containers ([#455](https://github.com/jameswlane/devex/issues/455)).

Connect with `postgresql://postgres@127.0.0.1:5432/postgres` and `redis://127.0.0.1:6379`.

```bash
devex status --template databases --run latest
devex remove --template databases --run latest --force   # keeps the data volumes
```

## Smoke procedure

Run this on a fresh Debian 12 or Ubuntu 24.04 VM. It needs `curl`, `git` and `unzip`, and sudo for the APT and Docker steps.

```bash
devex init --profile backend --non-interactive
devex template validate backend
devex template plan backend --action install --non-interactive
devex install --template backend --non-interactive --dry-run

devex plugin install package-manager-mise
devex plugin install package-manager-docker
devex install git curl Docker --non-interactive
devex plugin run package-manager-mise ensure-installed
devex install Go Python --non-interactive
devex install --template devops --answer tools=kubectl,helm --non-interactive
~/.local/bin/mise exec -- go version
~/.local/bin/mise exec -- python --version
~/.local/bin/mise exec -- kubectl version --client
~/.local/bin/mise exec -- helm version

# Log out and back in so the docker group applies, then:
devex install --template databases --answer databases=postgres,redis --answer mysql_password=unused --non-interactive
timeout 60 sh -c "until docker exec devex-postgres pg_isready; do sleep 2; done"
docker exec devex-redis redis-cli ping

devex list installed
devex remove --template databases --run latest --force
devex remove --template devops --run latest --force
```
