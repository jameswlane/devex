# Web Development

This page sets up a web development machine on Debian or Ubuntu with commands that work on the current CLI:

- Git, curl and the GitHub CLI from the application catalog
- Node.js through mise
- Optional PostgreSQL and Redis containers from the built-in `databases` lifecycle template

## Built-in web templates

DevEx ships two web templates:

| Template | Installs | Status |
| --- | --- | --- |
| `web-development` | mise, then Node.js 24 through mise | Installs on a fresh machine. It doesn't install VS Code or Chrome |
| `full-stack` | Git, curl, wget, Docker, PostgreSQL, Redis, VS Code, Chrome and Firefox Developer Edition | Stops at the VS Code snap on Ubuntu ([#462](https://github.com/jameswlane/devex/issues/462)) |

```bash
devex template info web-development
devex template plan web-development --action install --non-interactive
devex install --template web-development --non-interactive --dry-run
```

## Prepare

`devex init` writes the default application catalog. Catalog installs and template plans need it ([#466](https://github.com/jameswlane/devex/issues/466)).

```bash
devex init --profile frontend --non-interactive
```

Installs download the plugins their steps need, so you don't have to install the mise or Docker plugins first.

## Install the tools

```bash
# Git, curl and the GitHub CLI
devex install git curl "GitHub CLI" --non-interactive

# mise, then Node.js 24
devex install --template web-development --non-interactive
```

Pick another Node.js major version with `--answer node_version=22`.

mise adds its activation line to `~/.bashrc`. Open a new terminal to get `node` and `npm` on your PATH, or run them through `~/.local/bin/mise exec -- node`.

Use a major version such as `node@24`. The mise plugin rejects `node@lts`, so `devex install "Node.js"` fails ([#464](https://github.com/jameswlane/devex/issues/464)).

On Debian 12, `devex install "GitHub CLI"` installs Debian's older `gh` package instead of the current release from cli.github.com ([#472](https://github.com/jameswlane/devex/issues/472)).

## Local databases

The `databases` template runs PostgreSQL 16 and Redis 7 in Docker containers. They're published on 127.0.0.1 only, and data is kept in named volumes.

Install Docker Engine from the catalog first. The template's own Docker step fails on a fresh machine ([#470](https://github.com/jameswlane/devex/issues/470)).

```bash
devex install Docker --non-interactive
```

Then start the containers. Your session doesn't have the new `docker` group until you log out and back in, so DevEx runs `docker` with sudo until then:

```bash
devex install --template databases \
  --answer databases=postgres,redis \
  --non-interactive
```

Connect with `postgresql://postgres@127.0.0.1:5432/postgres` and `redis://127.0.0.1:6379`.

```bash
devex status --template databases --run latest
devex remove --template databases --run latest --force   # keeps the data volumes
```

## Editor and browser

DevEx doesn't install VS Code or Chrome on Debian and Ubuntu yet ([#553](https://github.com/jameswlane/devex/issues/553)). Install them from [code.visualstudio.com](https://code.visualstudio.com/) and [google.com/chrome](https://www.google.com/chrome/).

## Smoke procedure

Run this on a fresh Debian 12 or Ubuntu 24.04 VM. It needs `curl`, `git` and `unzip`, and sudo for the APT and Docker steps.

```bash
devex init --profile frontend --non-interactive
devex template validate web-development
devex template plan web-development --action install --non-interactive
devex install --template web-development --non-interactive --dry-run

devex install git curl "GitHub CLI" --non-interactive
devex install --template web-development --non-interactive
~/.local/bin/mise exec -- node --version
gh --version

devex install Docker --non-interactive

devex install --template databases --answer databases=postgres,redis --non-interactive
timeout 60 sh -c "until docker exec devex-postgres pg_isready; do sleep 2; done"
docker exec devex-redis redis-cli ping

devex list installed
devex remove --template databases --run latest --force
```
