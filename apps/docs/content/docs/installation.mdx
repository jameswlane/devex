# Installation Guide

DevEx provides multiple installation methods to suit different needs and preferences.

## Quick Install (Recommended)

The fastest way to get started with DevEx is using our one-line installer:

<Callout type="warn">
**Security Notice**: Before running any script with elevated privileges, review our [Security Best Practices](/docs/guides/security) guide. You can inspect the installer script first:

```bash
# Download and review the installer before execution
curl -fsSL https://get.devex.sh/install -o devex-install.sh
less devex-install.sh  # Review the script contents
```
</Callout>

```bash
curl -fsSL https://get.devex.sh/install | bash
```

The installer needs `curl`, `git` and `unzip`. If any are missing, it stops and prints the command that installs them.

This installer will:
1. **Download the latest DevEx release** for your platform
2. **Verify checksums** for security
3. **Install to** `~/.local/share/devex/`
4. **Update your PATH** for your current or explicitly selected shell
5. **Run the setup** with default configurations

### Shell PATH Configuration

On Linux and macOS, the installer chooses the shell from `$SHELL`, even when you
pipe the installer into `bash`. It updates only that shell's config: `~/.bashrc`
for bash, `~/.zshrc` for zsh, or `~/.config/fish/config.fish` for fish. On macOS,
bash also gets a PATH entry in `~/.bash_profile` for login shells. Existing config
files for other shells stay unchanged, and their config directories are never
created. Reinstalling does not add duplicate PATH entries.

Choose a different shell with `--shell bash|zsh|fish` or `DEVEX_SHELL`.
The flag takes precedence over the environment variable, which takes precedence
over `$SHELL`:

```bash
curl -fsSL https://get.devex.sh/install | bash -s -- --shell zsh --no-setup
curl -fsSL https://get.devex.sh/install | DEVEX_SHELL=fish bash -s -- --no-setup
```

The installer prints every file it changes or finds already configured. If
`$SHELL` is unset or unsupported, it installs the binary without changing any
shell config and prints instructions to select a shell or configure PATH manually.
Invalid explicit shell selections fail before installation.

To add DevEx to another shell manually, add the matching line to that shell's
config and restart the shell. Use your chosen install directory if you passed
`--install-dir`:

```bash
# Bash: ~/.bashrc (also ~/.bash_profile on macOS); zsh: ~/.zshrc
export PATH="$PATH:$HOME/.local/share/devex/bin"
```

```fish
# Fish: ~/.config/fish/config.fish
set -gx PATH $PATH "$HOME/.local/share/devex/bin"
```

### What Gets Installed

The quick installer automatically installs all applications marked with `default: true` in the configuration files:

- **Development tools**: Git, GitHub CLI, Neovim, fzf, ripgrep
- **Programming languages**: Node.js LTS (via mise)
- **System utilities**: curl, htop, tree
- **Desktop themes**: Tokyo Night theme for GNOME
- **Shell configuration**: Zsh with Oh My Zsh (if selected)

## Manual Installation

For more control over the installation process:

### 1. Download the Binary

Visit the [GitHub releases page](https://github.com/jameswlane/devex/releases) and download the appropriate binary for your system:

```bash
# Example for Linux x86_64 - pin a specific version (archive names omit the "v")
VERSION=0.3.0
curl -fsSLO "https://github.com/jameswlane/devex/releases/download/v${VERSION}/devex_${VERSION}_linux_amd64.tar.gz"

# Verify the checksum (recommended)
curl -fsSLO "https://github.com/jameswlane/devex/releases/download/v${VERSION}/devex_checksums.txt"
# Extract only if the checksum matches (the archive holds bin/devex plus its assets, config and help)
sha256sum -c --ignore-missing devex_checksums.txt &&
  mkdir -p ~/.local/share/devex &&
  tar -xzf "devex_${VERSION}_linux_amd64.tar.gz" -C ~/.local/share/devex

# Add it to PATH now and for new shells (use ~/.zshrc for zsh)
export PATH="$HOME/.local/share/devex/bin:$PATH"
echo 'export PATH="$HOME/.local/share/devex/bin:$PATH"' >> ~/.bashrc
```

### 2. Initialize Configuration

```bash
# Create configuration directory
mkdir -p ~/.local/share/devex/config

# Download default configurations
devex config init
```

### 3. Run Setup

```bash
# Install with dry-run to preview changes
devex install --dry-run

# Install default applications
sudo devex install

# Or install specific categories
sudo devex install --category development
```

## Platform-Specific Instructions

<Callout type="info">
For detailed platform-specific configurations, see our [Platform Guides](/docs/platforms). For automated deployment, check our [Automation Guide](/docs/guides/automation).
</Callout>

### Linux (Ubuntu/Debian)

```bash
# Prerequisites - Install required tools
sudo apt update
sudo apt install -y curl git unzip ca-certificates

# Install DevEx (review security guide first)
curl -fsSL https://get.devex.sh/install | bash
```

### Linux (Fedora/RHEL)

```bash
# Prerequisites - Install required tools
sudo dnf install -y curl git unzip ca-certificates

# Install DevEx (review security guide first)
curl -fsSL https://get.devex.sh/install | bash
```

### Linux (Arch)

```bash
# Prerequisites - Install required tools
sudo pacman -S curl git unzip ca-certificates

# Install DevEx (review security guide first)
curl -fsSL https://get.devex.sh/install | bash
```

### macOS

```bash
# Using Homebrew (recommended - most secure)
brew install jameswlane/tap/devex

# Or using the installer (review security guide first)
curl -fsSL https://get.devex.sh/install | bash
```

### Windows

Windows support is minimal for now: the installer and the CLI run, but Windows package managers are not supported yet. The installer needs `git`.

```powershell
irm https://get.devex.sh/install.ps1 | iex
```

## Docker Installation

For containerized environments:

```bash
# Run DevEx in a container
docker run --rm -it \
  -v $HOME/.devex:/root/.devex \
  -v $HOME/.local/share/devex:/root/.local/share/devex \
  jameswlane/devex:latest

# Or build from source
git clone https://github.com/jameswlane/devex.git
cd devex
docker build -t devex .
```

## CI/CD Integration

<Callout type="tip">
For comprehensive CI/CD integration examples and advanced automation patterns, see our detailed [Automation Guide](/docs/guides/automation).
</Callout>

### GitHub Actions

```yaml
name: Setup Development Environment
on: [push, pull_request]

jobs:
  setup:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Install DevEx
        run: |
          # Pin to specific version for CI reproducibility
          wget -qO- https://get.devex.sh/install | bash
          echo "$HOME/.local/share/devex/bin" >> $GITHUB_PATH
      
      - name: Setup environment
        run: devex install --category development
```

### GitLab CI

```yaml
setup_environment:
  stage: setup
  image: ubuntu:22.04  # Pin to specific version
  before_script:
    - apt-get update && apt-get install -y curl git unzip sudo ca-certificates
  script:
    # Pin to specific version for CI reproducibility
    - curl -fsSL https://get.devex.sh/install | bash
    - export PATH="$PATH:$HOME/.local/share/devex/bin"
    - devex install --dry-run
```

## Verification

After installation, verify DevEx is working correctly:

```bash
# Check version
devex --version

# Validate configuration
devex config validate

# List available installers
devex install --list

# Check system compatibility
devex system info
```

## Uninstallation

To completely remove DevEx:

```bash
# Remove installed applications (if desired)
devex uninstall --all

# Remove DevEx binary and data
rm -rf ~/.local/share/devex
rm -rf ~/.devex

# Remove from PATH (edit ~/.bashrc)
# Remove the line: export PATH="$PATH:$HOME/.local/share/devex/bin"
```

## Troubleshooting

<Callout type="info">
For comprehensive troubleshooting guidance, see our [Troubleshooting Guide](/docs/guides/troubleshooting). For configuration issues, check the [Configuration Guide](/docs/configuration).
</Callout>

### Permission Issues

If you encounter permission errors:

```bash
# Ensure proper ownership
sudo chown -R $USER:$USER ~/.local/share/devex
sudo chown -R $USER:$USER ~/.devex

# Fix binary permissions
chmod +x ~/.local/share/devex/bin/devex
```

### Network Issues

If downloads fail:

```bash
# Use curl instead of wget (with certificate verification)
curl -fsSL https://get.devex.sh/install | bash

# Or set proxy with security considerations
export https_proxy=http://your-proxy:port
export http_proxy=http://your-proxy:port
curl -fsSL https://get.devex.sh/install | bash
```

### Configuration Issues

If configuration loading fails:

```bash
# Reset to defaults
devex config reset

# Validate configuration
devex config validate

# Debug mode
devex --verbose install --dry-run
```
