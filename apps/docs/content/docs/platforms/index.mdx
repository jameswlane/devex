# Platform Support Overview

Debian/Ubuntu with APT is the stable path. Other existing managers are
experimental; a plugin's presence or platform metadata does not establish a
fully tested setup experience.

## Support matrix

This matrix is manually maintained from the repository's
[package manager metadata and implementations](https://github.com/jameswlane/devex/tree/main/packages).
Metadata describes platform eligibility and capabilities, but does not encode
stable/experimental/planned status or managers with no plugin. Review this page
and root CLI help together when support changes.

- **Stable**: the primary supported installation path, with automated coverage.
- **Experimental**: a plugin exists, but full platform lifecycle validation or
  advertised capabilities remain incomplete. Review the linked limitations.
- **Planned**: no package manager plugin exists; configuration entries alone do
  not make a manager usable.

These levels describe DevEx integration, not the upstream package manager's
quality. Native command tests do not establish support for every OS release,
architecture, desktop environment, repository, or package.

## Before installing

Review the selected applications, implicit dependencies and configuration changes
with `devex install --dry-run` or the setup confirmation screen. Install only the
plan you intend to apply. Optional package managers and desktop settings are not
blanket permission to change the system; see the
[consent rules #271](https://github.com/jameswlane/devex/issues/271).

For machine-readable planning, use `devex install --dry-run --format json`.
Support information on this page does not add diagnostics to JSON stdout.
