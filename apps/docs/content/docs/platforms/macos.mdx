# macOS Support

macOS integration is **experimental**. A Homebrew plugin exists, but this is not
a claim of full macOS setup, release or architecture coverage. Debian/Ubuntu
checks do not validate native macOS behavior.

## Homebrew: experimental

See [Homebrew user execution and Cask selections #109](https://github.com/jameswlane/devex/issues/109)
for remaining integration work. Do not assume DevEx automatically provisions
Xcode Command Line Tools, Homebrew, Rosetta, or system preferences. Review and
explicitly choose prerequisite installations and configuration changes.

## Planned managers

There are no DevEx plugins for these managers yet. Their presence in application
configuration does not make those installation paths available.

- [Mac App Store (mas) plugin #110](https://github.com/jameswlane/devex/issues/110)
- [MacPorts plugin #124](https://github.com/jameswlane/devex/issues/124)

## Deferred integration

Native verification and platform implementation remain in their tracking issues:
[Git and Xcode prerequisites #129](https://github.com/jameswlane/devex/issues/129),
[authorization scope #126](https://github.com/jameswlane/devex/issues/126), and
[opt-in application grouping #176](https://github.com/jameswlane/devex/issues/176).
No release date or complete feature parity is promised here. Consult the
[support matrix](/platforms) and
[consent rules #271](https://github.com/jameswlane/devex/issues/271).
