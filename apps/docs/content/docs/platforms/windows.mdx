# Windows Support

Native Windows package management is **planned**. No winget, Chocolatey or
Scoop plugin exists in this repository. Windows entries in application
configuration describe intended methods, not working DevEx installers.

## Planned managers

- [winget plugin #111](https://github.com/jameswlane/devex/issues/111)
- [Chocolatey plugin #112](https://github.com/jameswlane/devex/issues/112)
- [Scoop plugin #113](https://github.com/jameswlane/devex/issues/113)

## Deferred integration

[Privilege elevation #133](https://github.com/jameswlane/devex/issues/133),
[PowerShell configuration #135](https://github.com/jameswlane/devex/issues/135),
and [Windows Terminal profiles #136](https://github.com/jameswlane/devex/issues/136)
track additional native work. Native validation is deferred; no Windows release
compatibility or delivery date is promised.

## WSL

DevEx running inside WSL uses the Linux distribution's tools and support level.
Debian/Ubuntu APT support does not imply support for Windows host applications,
registry changes, PowerShell profiles or Windows package managers. WSL-specific
integration is not verified by Debian/Ubuntu container tests.

See the [Linux guide](/platforms/linux), [support matrix](/platforms)
and [consent rules #271](https://github.com/jameswlane/devex/issues/271).
