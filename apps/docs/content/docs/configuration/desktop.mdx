# Desktop Configuration

Desktop settings live under `desktop/<environment>/` in the default tree at `~/.local/share/devex/config/`. Personal overrides use the same tree under `~/.devex/config/`.

```text
desktop/
└── gnome/
    ├── themes/themes.yaml
    ├── settings/settings.yaml
    ├── extensions/extensions.yaml
    └── dock/dock.yaml
```

The loader recognizes `gnome`, `kde`, `macos`, and `windows` environment directories. Each YAML file contains one or more setting groups at the root; it does not need a `desktop_environments:` wrapper. Nested files are processed alphabetically.

## Themes

```yaml
# desktop/gnome/themes/themes.yaml
themes:
  - name: Adwaita Dark
    theme_color: dark
```

## Extensions

```yaml
# desktop/gnome/extensions/extensions.yaml
extensions:
  - name: Tactile
    id: tactile@lundal.io
```

## Settings and dock

Use `settings` and `dock` lists in the corresponding files. The shipped GNOME files provide examples of setting groups and dock items. A later file or higher tier replaces a setting group when it supplies that group; omitted groups retain their lower-priority values.

Desktop application installations belong in `applications/<category>/<app>.yaml`, using the cross-platform [application schema](/configuration/applications). Use an application's `desktop_environments` field when it should be available only on selected desktop environments.

```bash
devex config edit desktop
devex config validate
```

The desktop directory is optional. Legacy root files such as `desktop.yaml`, `desktop-optional.yaml`, `gnome.yaml`, and `kde.yaml` continue loading with a deprecation warning. Move application entries into `applications/` and desktop setting groups into `desktop/<environment>/`.
