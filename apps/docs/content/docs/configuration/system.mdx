# System Configuration

The canonical system files live under `~/.local/share/devex/config/system/`. Personal overrides use `~/.devex/config/system/`.

```text
system/
├── git.yaml
├── global.yaml
├── ssh.yaml          # Optional
└── terminal.yaml     # Optional
```

## Git

`system/git.yaml` contains a Git settings object at the root:

```yaml
aliases:
  co: checkout
  br: branch
  ci: commit
  st: status
settings:
  pull:
    rebase: true
```

The loader also accepts a YAML list of Git settings objects in this file. Do not add a `git:` wrapper inside `system/git.yaml`.

## Global theme

```yaml
# system/global.yaml
global_theme: Tokyo Night
```

## SSH and terminal

Optional `system/ssh.yaml` and `system/terminal.yaml` contain the SSH and terminal settings maps directly, without an outer `ssh:` or `terminal:` wrapper. Reading these settings does not itself apply them to the host.

## Root compatibility settings

`dotfiles.yaml` remains a supported root file containing `git`, `ssh`, `terminal`, and `global_theme` settings. Corresponding files in `system/` override it within the same tier. `security.yaml` remains a supported root file for security configuration. Neither root file produces a deprecation warning.

```bash
devex config show --detailed
devex config edit system
devex config validate
```

`config edit all` also opens the existing root settings files. The legacy root `system.yaml` still loads with a deprecation warning; move its setting groups into the files above.
