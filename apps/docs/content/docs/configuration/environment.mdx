# Environment Configuration

Language, font, and shell definitions use separate files:

```text
~/.local/share/devex/config/environments/
├── programming-languages/go.yaml
├── fonts/fira-code.yaml
└── shell/
```

Personal overrides use the same tree under `~/.devex/config/environments/`. This directory also contains optional environment-specific tiers such as `environments/prod/applications/`; see [configuration priority](/configuration#configuration-priority).

## Programming languages

Shipped language files use flat installation fields:

```yaml
# environments/programming-languages/go.yaml
name: Go
description: Go programming language
category: Programming Languages
install_method: mise
install_command: go@latest
uninstall_command: go
default: false
dependencies:
  - mise
```

Languages and shell applications also accept the cross-platform blocks described in [applications](/configuration/applications). They appear in `devex list available` alongside the application catalog.

## Fonts

Each font file contains one font at its root:

```yaml
# environments/fonts/fira-code.yaml
name: Fira Code
method: url
url: https://github.com/ryanoasis/nerd-fonts/releases/latest/download/FiraCode.zip
destination: ~/.local/share/fonts
```

Font definitions load into font settings, rather than the application catalog.

## Shell applications

Place optional shell installation definitions in `environments/shell/<shell>.yaml`:

```yaml
# environments/shell/zsh.yaml
name: zsh
description: Z shell
category: Shells
install_method: apt
install_command: zsh
uninstall_command: zsh
default: false
```

Use platform blocks when a shell needs a different installation method on another OS. A shell name recorded in init metadata is a preference; it does not replace an installation definition.

```bash
devex config edit environment
devex config validate
```

The legacy `environment.yaml`, `programming-languages.yaml`, `fonts.yaml`, and `shell.yaml` files remain readable with a deprecation warning. Move each list entry into a separate file in the relevant directory and remove its list wrapper.
